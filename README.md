## Selected work

**[auricle](https://github.com/himanshu007-creator/auricle)** ([demo](https://himanshu007-creator.github.io/auricle/))
Voice activity detection, turn taking and barge-in for voice agents, in Rust compiled to WebAssembly. A drop-in for `vad-web`. Published on npm.

**[passit](https://github.com/himanshu007-creator/passit)**
A local-first MCP server that hands a conversation from one coding agent to another and lets you continue. Rust, SQLite, published on crates.io.

**[contractwatch](https://github.com/himanshu007-creator/contractwatch)** ([docs](https://himanshu007-creator.github.io/contractwatch/))
Catches breaking FastAPI changes before clients do. Diffs the OpenAPI contract in pre-commit and CI. Python, published on PyPI.

**[sketchetc](https://github.com/himanshu007-creator/sketchetc)** ([site](https://himanshu007-creator.github.io/sketchetc/))
A SketchyBar setup for macOS: themes, widgets, clipboard history and a tamper-proof journal. Shell and Swift.

**[Yaadon Ki Rasoi](https://github.com/himanshu007-creator/yaadon-ki-rasoi)** ([live](https://yaadon-ki-rasoi.vercel.app))
Describe a dish from your childhood that you can't name, and it finds candidates and the regional names for it. TypeScript.

**[Vyral](https://github.com/himanshu007-creator/Vyral)** ([live](https://vyral-ivory.vercel.app))
A parody in-game phone built around the Unlayer React image editor. JavaScript.
